# Deep Money Special 01
## Singapore TOTO — One Million Simulations

### Can S$18 Beat Randomness?

This project is a statistical experiment using Singapore TOTO.

Rather than attempting to predict lottery numbers from intuition alone, the experiment examines historical TOTO results against large-scale computer simulations.

The central question is simple:

> If Singapore TOTO is simulated one million times, how unusual are the patterns observed in the actual historical results?

The experiment then goes one step further.

Using the statistical observations generated from historical data and simulations, one set of six numbers will be selected for each live draw.

A total budget of S$18 has been fixed in advance.

---

## Live Experiment Rules

- Initial bankroll: **S$18**
- Bet size: **S$1 per draw**
- Maximum live draws: **18**
- Additional funding: **Not allowed**
- One set of six numbers per draw
- Each prediction must be recorded before the relevant draw
- The experiment ends after 18 live bets, regardless of the outcome

These rules are fixed before the first live bet.

---

## Research Approach

The project will examine:

- Historical number frequencies
- Hot and cold numbers
- Number absence intervals
- Consecutive numbers
- Odd / even distributions
- Sum distributions
- Repeated numbers between draws
- Number pairs and combinations
- Rolling 50-draw and 100-draw patterns
- Monte Carlo simulations
- Backtesting of different number-selection strategies

The purpose is not to assume that historical patterns can predict future lottery results.

Instead, the objective is to measure how much apparent structure can emerge from randomness — and whether the real TOTO history looks unusual when compared with simulated random draws.

---

## Final Stage

After each statistical analysis, the data will be used as information for selecting one set of six numbers.

The final selection remains a human decision.

**AI and Python analyze the randomness.  
A human chooses the numbers.**

All predictions and results will be recorded in this repository.
