# Deep Money

**ニュースの下を流れる「お金」を追う。**

Deep Moneyは、経済の物語、市場のニュース、金融イベントの裏側で、資本が実際にどのように動いているのかを調査する独立リサーチプロジェクトです。

たとえば、

- 地方銀行は危ないのか？
- AI投資はバブルなのか？
- 不動産価格は高すぎるのか？
- 金利上昇は危険なのか？

といった問いだけで終わらず、Deep Moneyではそこからもう一段深く掘り下げます。

その背後にあるバランスシート、キャッシュフロー、資本構造、株主構成、負債、そして経済的インセンティブを調べることを目的とします。

## Research Approach

出発点になるのは、多くの場合、単純な観察、違和感、あるいは疑問です。

そこから一次データと金融上のEvidence（根拠）へと降りていきます。

基本的なプロセスは、

**Observation → Question → Data → Structure → Evidence → Interpretation**

です。

**観察 → 疑問 → データ → 構造 → 根拠 → 解釈**

目的は市場を予測することではありません。

その下に存在する金融構造を理解することです。

## Current Research

### 日本の信用金庫 — 金利上昇リスク

日本が再び「金利のある世界」へ戻りつつあることで、長年の超低金利環境の中で形成されてきたバランスシート構造が表面化し始めています。

Deep Moneyの最初のリサーチでは、日本全国の信用金庫を対象として、以下の関係を調査します。

- 預金
- 貸出金
- 有価証券
- 日本国債
- 有価証券の含み損益
- 自己資本

最初の問いはシンプルです。

> 個別の信用金庫で表面化している問題は特殊なケースなのか。それとも、信用金庫業界に存在する、より広い構造的パターンの一部なのか？

まず全国の信用金庫をスクリーニングし、その後、個別金融機関のバランスシートへと調査を進めます。

## Research Principles

Deep Moneyでは、次の3つを分けて考えます。

**Fact（事実）** — データが実際に示していること。

**Interpretation（解釈）** — そのデータが何を意味する可能性があるのか。

**Hypothesis（仮説）** — 次に何を調べるべきなのか。

この3つを混同しません。

新しいEvidenceが得られるたびに、リサーチは更新していきます。
